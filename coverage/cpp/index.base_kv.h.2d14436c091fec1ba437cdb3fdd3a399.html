20 ===============================================================
21 使用指南：如何配置 KV 引擎（engine）与内存管理（allocator）
22 ===============================================================
23
24 一、总体原则
25 -----------
26 1) 你只需要配置 **index_type** 与 **value_type**，具体用哪个引擎由
27 `base::ResolveEngine(cfg)` 自动推导，再交给工厂创建。
28 - value_type = HYBRID → KVEngineHybrid
29 - value_type ∈ {DRAM, SSD}
30 且 index_type = DRAM → KVEngineExtendibleHash
31 且 index_type = SSD → KVEngineCCEH
32 2) 内存管理实现（allocator）推荐通过
33 `json_config_["allocator_type"]` 选择：
34 - "PERSIST_LOOP_SLAB"（默认）
35 - "R2_SLAB"
36 `value_memory_management` 由 `allocator_type` 推导填充（见 allocator
37 归一化）。
38
39 二、必须/可选配置字段
40 -------------------
41 必填（非 HYBRID）：
42 - "path" : 工作目录（每个实例建议唯一）
43 - "index_type" : "DRAM" | "SSD"
44 - "value_type" : "DRAM" | "SSD"
45 - "value_size" : 每条 value 字节数（例如 128）
46 - "DRAM_SIZE"/"SSD_SIZE" : 对应 value 介质容量预算（字节，二选一）
47 或显式给 "capacity"（按条数）
48
49 必填（HYBRID）：
50 - "path" : 工作目录
51 - "index_type" : "DRAM" | "SSD"
52 - "value_type" : "HYBRID"
53 - "shmcapacity" : DRAM/SHM 侧字节数预算
54 - "ssdcapacity" : SSD 侧字节数预算
55
56 可选：
57 - "allocator_type" : "PERSIST_LOOP_SLAB" | "R2_SLAB"
58 - "value_layout" : "FIXED" | "VARIABLE"（VARIABLE 仅 HYBRID 支持）
59 默认分配器是 PERSIST_LOOP_SLAB
60
61 三、推荐创建流程（示例 C++）
62 ---------------------------
63 BaseKVConfig cfg;
64 cfg.num_threads_ = 16;
65 cfg.json_config_ = {
66 {"path", "/tmp/recstore"},
67 {"index_type", "DRAM"},
68 {"value_type", "SSD"},
69 {"DRAM_SIZE", 128000000},
70 {"value_size", 128},
71 {"allocator_type", "PERSIST_LOOP_SLAB"} // 或 "R2_SLAB"
72 };
73
74 // 由 (index_type, value_type) 推导 engine_type，并补齐/校验必需字段
75 auto r = base::ResolveEngine(cfg);
76
77 // 用工厂创建（确保相应引擎与分配器已在本进程中注册/链接）
78 std::unique_ptr<BaseKV> kv(
79 base::Factory<BaseKV, const BaseKVConfig&>::NewInstance(r.engine, r.cfg)
80 );
81 if (!kv) throw std::runtime_error("Create KV engine failed: " + r.engine);
