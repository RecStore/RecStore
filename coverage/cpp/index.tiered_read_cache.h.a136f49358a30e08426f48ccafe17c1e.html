14 // Access-driven DRAM read cache for the tiered value store.
15 //
16 // The tiered store picks DRAM or SSD once, in Alloc(), so the DRAM layer ends
17 // up holding whatever was written first instead of what is read most. This
18 // cache keeps a second copy of hot SSD values in DRAM, keyed by the raw SSD
19 // handle, so a value that was placed on SSD can still be served from DRAM after
20 // it has been read once.
21 //
22 // It is sharded (one mutex, one LRU list and one byte cap per shard) because a
23 // single mutex turns every DRAM hit into a serialization point. A hit copies
24 // out while holding its shard lock: the copy is a memcpy of one value, and
25 // holding the lock is what makes evicting the same slot safe.
26 //
27 // The cap per shard is `min(configured budget, shared DRAM watermark - primary
28 // placement) / shards`, so the cache and primary placement together stay inside
29 // one watermark instead of each assuming it owns the whole DRAM layer. A full
30 // shard evicts its LRU entry before admitting a new one; refusing instead would
31 // freeze the cache on the first values it ever saw.
32 //
33 // `promote_min_misses` filters admission: with 2, a key is only copied into
34 // DRAM on its second miss. One-shot misses (a scan, a cold tail) would
35 // otherwise each cost a DRAM slot and evict a genuinely hot entry, which is
36 // what keeps the hit rate far below what the workload's frequency skew allows.
37 //
38 // Promotion is guarded by a write barrier. A reader captures a per-key token
39 // before it reads SSD and only inserts its copy if no Write, BatchWrite or Free
40 // bumped that key in the meantime. Without it, this interleaving leaves a stale
41 // value cached forever: reader fetches the old value, writer overwrites the
42 // slot (WriteThrough finds no entry, so it only bumps the token), reader
43 // inserts the old copy.
44 //
45 // Deliberately not built on `storage/cache/lru/lru_cache.h`: that module tracks
46 // keys only (no values, no byte budget, no atomic lookup-and-copy), so it
47 // cannot serve a read path.
